## 📌 Project Overview

This project performs an in-depth analysis of hotel booking cancellation patterns using **Microsoft Excel**. Through pivot tables, dynamic charts, and interactive dashboards, this project uncovers the key drivers behind booking cancellations in the hospitality industry — offering actionable business intelligence for hotel management.

> 🎯 **Goal**: Identify patterns, trends, and factors influencing hotel booking cancellations to help hotels reduce loss and improve customer retention.

## 🔍 Key Insights & Findings

| Insight | Finding |
|---------|---------|
| 📉 Cancellation Rate | ~37% of all bookings were cancelled |
| 🏙️ City Hotels | Higher cancellation rate compared to Resort Hotels |
| 📅 Lead Time Impact | Longer lead time → higher cancellation probability |
| 💳 Deposit Type | "No Deposit" bookings have the highest cancellation rate |
| 🌍 Top Market Segment | Transient customers cancel the most |
| 📆 Peak Cancellation Month | August sees the highest number of cancellations |

## 📈 Analysis Sections

### 1️⃣ Booking Overview
- Total bookings, cancellations, and confirmed bookings
- Hotel type comparison (City vs Resort)

### 2️⃣ Cancellation Trend Analysis
- Monthly and yearly cancellation trends
- Seasonality patterns in bookings

## 🚀 How to Use

1. **Download** the `Hotel_Booking.xlsx` file
2. **Open** it in Microsoft Excel (2016 or later recommended)
3. Navigate to the **Dashboard** sheet for the interactive overview
4. Use **slicers** (Hotel Type, Year, Country) to filter data dynamically
5. Explore individual **analysis sheets** for deep dives

## 📋 Dataset Information

- **Source**: [Kaggle — Hotel Booking Demand Dataset](https://www.kaggle.com/jessemostipak/hotel-booking-demand)
- **Records**: 119,390 hotel bookings
- **Period**: July 2015 – August 2017
- **Hotels**: Two hotel types (City Hotel & Resort Hotel)
- **Features**: 32 variables including booking dates, room types, customer details, etc.
